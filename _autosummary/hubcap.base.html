You need to specify a token in auth, or in the environment variable HUBCAP_GITHUB_TOKEN or GITHUB_TOKEN.

The iteration is defined to be the repositories of the account_name (could be organization name).

class hubcap.base.Issues(repo, get_objs=<function Repository.get_issues>, *, objs_to_items='number', data_of_obj=<function identity>, get_objs_kwargs=(('state', 'open'), ), cache=False, refresh=True)[source]#

Bases: RepoObjects

Mapping interface to repository issues.

Parameters:

  • repo (Union[str, Repository]) – The repository to get issues from

  • get_objs – The function to get the issues

  • objs_to_items – A function to get the key-value pairs from the issue objects

  • data_of_obj – A function to get the data from the issue object. Default is attrgetter(‘body’). Use identity to get the whole issue object.

  • get_objs_kwargs – The keyword arguments to pass to the get_objs function

  • cache (bool) – If True, cache issue data to local storage

  • refresh (bool) – If True, always fetch fresh data from GitHub and update cache

The default of data_of_obj is IssueContents, which will give a mapping interface to the body and comments of the issue.
